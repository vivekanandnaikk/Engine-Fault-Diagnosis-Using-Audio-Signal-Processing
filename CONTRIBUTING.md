# Contributing

Contributions that improve reproducibility, tests, documentation, or safe handling of audio are welcome.

- Open an issue before substantial changes.
- Add or update tests for Python signal-processing changes.
- Do not commit private recordings, personal information, or unlicensed datasets.
- Document MATLAB version and toolbox requirements when changing MATLAB code.
- Run `pytest` and report environment limitations in the pull request.
- Do not submit unsupported diagnostic accuracy or safety claims.

This project is educational and is not intended for safety-critical use.
