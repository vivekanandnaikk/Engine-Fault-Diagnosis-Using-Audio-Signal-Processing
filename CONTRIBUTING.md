# Contributing

Contributions that improve reproducibility, tests, documentation, or safe handling of audio are welcome.

- Open an issue to describe substantial changes before starting implementation.
- Keep changes consistent with the reconstructed-reference status; do not imply that original recordings or a validated diagnosis are present.
- Add or update tests for changes to Python signal processing.
- Do not commit private recordings, personal information, unlicensed datasets, or unsupported accuracy claims.
- Document MATLAB version/toolbox assumptions when changing the MATLAB function.
- Run `pytest` and report any environment limitations in the pull request.

This project is educational and is not intended for safety-critical use.
