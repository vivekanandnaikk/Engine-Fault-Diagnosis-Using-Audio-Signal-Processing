# Project plan

The current repository is a DSP reference implementation. The items below are proposals, not completed project claims.

- [ ] Collect permission-cleared recordings and document machine, recording conditions, labels, and provenance.
- [ ] Define a repeatable recording and segmentation protocol across RPM/load conditions.
- [ ] Validate Python and MATLAB outputs against known test signals and document feature conventions.
- [ ] Add optional plots for waveform and spectrum, with tests and clearly labelled units.
- [ ] Evaluate feature variability across repeated takes before considering any thresholds.
- [ ] If automatic classification is pursued, collect a representative labelled dataset and use a subject/session-separated evaluation protocol; report metrics and uncertainty.
- [ ] Consider time-varying spectral features only when supported by a documented requirement.

Do not represent proposed work as implemented. Any diagnostic claims require independent evidence and an appropriately controlled evaluation; this project is not safety-certified.
