# Project plan

The current implementation provides a reproducible core DSP analysis workflow. Suggested future work includes:

- [ ] Add permission-cleared and documented engine recordings.
- [ ] Define a repeatable recording and segmentation protocol across RPM/load conditions.
- [ ] Validate Python and MATLAB outputs against known test signals.
- [ ] Add optional waveform and spectrum plots with tests and labelled units.
- [ ] Evaluate feature variability across repeated takes before defining thresholds.
- [ ] If automatic classification is pursued, collect representative labelled data and use an appropriate subject/session-separated evaluation protocol.
- [ ] Report uncertainty and evaluation limitations for every future diagnostic result.
- [ ] Consider time-varying spectral features or adaptive processing only when justified and documented.

Any future diagnostic capability requires controlled evidence and validation. The project remains educational and is not safety-certified.
