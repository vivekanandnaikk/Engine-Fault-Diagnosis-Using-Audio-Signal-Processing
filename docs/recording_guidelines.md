# Recording guidelines

For comparisons to be interpretable, record the conditions alongside each WAV file. These suggestions do not guarantee that recordings are diagnostically valid.

- Keep the phone's position, distance, orientation, and case consistent.
- Record comparable RPM, engine load, warm-up state, and duration; note these for every take.
- Use the same device and audio settings where possible. Mobile phones may apply automatic gain control, compression, and noise reduction.
- Record in a quiet, consistent environment and note unusual background noise.
- Capture multiple takes for each condition instead of relying on one clip.
- Preserve the original recording and avoid undocumented filtering, resampling, or normalization.
- Use filenames or a separate metadata sheet to identify label, date, take, RPM/load (if known), device, and setup. Do not put personal information in public filenames.
- Obtain permission before recording people or publishing audio; exclude sensitive or private recordings from commits.

A feature difference between recordings is not proof of a fault. Seek inspection by a qualified mechanic for actual vehicle concerns.
